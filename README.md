# Happy Shopping OMS + CRM (Mockup)

ระบบจัดการออเดอร์ + แชทลูกค้ารวมทุกช่องทาง (Shopee, Lazada, TikTok Shop, LINE OA, Facebook, Instagram)

> ⚠️ **นี่คือ mockup สำหรับนำเสนอ** — ไม่มี backend/ฐานข้อมูล/การเชื่อมต่อแพลตฟอร์มจริง
> อ่าน **[PROJECT_STATUS.md](./PROJECT_STATUS.md)** ก่อนเริ่มพัฒนาระบบจริง ว่าอะไรทำแล้ว/ยังไม่ได้ทำ

- Production: https://happyomnichannel.vercel.app
- Local (Docker): `docker compose up -d --build` → http://localhost:3456
- Dev: `npm install && npm run dev`

Stack: Next.js 16 · React 19 · Tailwind CSS 4 · shadcn/ui (base-ui) · Recharts
